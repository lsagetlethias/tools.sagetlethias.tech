Petits outils auto-hébergés, libres et sans base de données.

  • caldav2ics

    Transforme un calendrier CalDAV protégé par identifiants en lien ICS lisible par Google Calendar, Outlook ou Apple Calendar. Les identifiants sont chiffrés dans le slug, rien n'est stocké.

    Ouvrir l'outil Code source caldav2ics.tools.sagetlethias.tech

  • Fine-Grained Proxy

    Proxy HTTP stateless qui ajoute des tokens à granularité fine devant n'importe quelle API : scope par méthode, par chemin et par contenu du body, durée de vie limitée. Toute la configuration est chiffrée dans l'URL.
